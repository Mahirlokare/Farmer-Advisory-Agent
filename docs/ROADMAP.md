# Delivery roadmap

## Phase 0 — Repository foundation
- [x] Monorepo structure, API health check, multilingual UI shell, API contract and tests.
- [x] Explicit safe behavior while knowledge and vision models are not connected.
- [ ] CI, dependency lockfiles, security scanning and deployment environments.

## Phase 1 — Reliable data foundation
- [ ] Curate ICAR/state agricultural university/KVK documents with source licensing review.
- [ ] Build ingestion, OCR, chunking, metadata and review workflow.
- [ ] Create crop, variety, growth-stage, region, soil and pest/disease taxonomies.
- [ ] Implement citation-grounded retrieval and evaluation.

## Phase 2 — Farmer workflows
- [ ] Farmer/farm profiles with consent and data minimization.
- [ ] Crop calendar, sowing and irrigation decision support.
- [ ] Weather forecast alerts and official mandi-price adapter.
- [ ] Government scheme directory with eligibility source/date and official links.
- [ ] Human expert escalation and feedback loop.

## Phase 3 — Multimodal intelligence
- [ ] Validated crop disease image model with per-class metrics and out-of-distribution rejection.
- [ ] Speech-to-text and text-to-speech for six launch languages.
- [ ] Regional terminology, transliteration and farmer usability testing.
- [ ] Offline/low-connectivity PWA behavior.

## Phase 4 — Production readiness
- [ ] Security/privacy review, threat model and penetration testing.
- [ ] Load, reliability, accessibility and device testing.
- [ ] Agricultural expert validation across agro-climatic zones.
- [ ] Model cards, dataset cards, monitoring, rollback and incident response.

A feature is not production-ready merely because its UI exists. Each AI feature requires documented datasets, validation metrics, field testing and human escalation.
